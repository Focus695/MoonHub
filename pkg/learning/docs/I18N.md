# MoonHub i18n 架构

MoonHub 学习系统使用模块化的 i18n 架构支持多语言。
## 架构
### 核心组件
```
pkg/learning/
├── i18n/
│   ├── i18n.go          # 国际化管理器
│   ├── en.go            # 英文资源
│   └── zh.go            # 中文资源
├── patterns/
│   ├── patterns.go      # 模式管理器
│   ├── en_patterns.go   # 英文模式
│   └── zh_patterns.go   # 中文模式
└── types.go             # 配置定义
```
### 数据流
1. 配置加载 → `Config.Language`
2. 初始化 → `i18n.New(lang)` → `patterns.NewManager()`
3. 模式检测 → `detector.DetectSignals()`
4. 语言检测 → `i18n.DetectLanguage(text)`
5. 模式匹配 → `patterns.GetPatterns(lang)`
## 添加新语言
### 1. 创建文本资源
```go
// pkg/learning/i18n/ja.go
package i18n

func initJapanese() TextResources {
    return TextResources{
        Suggestions: SuggestionsText{
            ToolLowSuccess: TitleDesc{
                Title:       "ツールの使用状況を確認",
                Description: "このツール成功率较低。別の方法を検討してください。",
            },
            // ...
        },
        Context: ContextText{
            Preferences: "## 学習した設定",
            // ...
        },
    }
}
}
```

### 2. 创建模式定义
```go
// pkg/learning/patterns/ja_patterns.go
package patterns

import "regexp"

func initJapanesePatterns() PatternSet {
    return PatternSet{
        Positive: []*regexp.Regexp{
            regexp.MustCompile(`すごい|完璧|素晴らしい`),
            // ...
        },
        // ...
    }
}
}
```

### 3. 注册语言
在 `i18n/i18n.go` 中添加:
```go
case "ja":
    i.texts[LangJa] = initJapanese()
```

在 `patterns/patterns.go` 中添加:
```go
case "ja":
    m.patterns[LangJa] = initJapanesePatterns()
    m.semantics[LangJa] = initJapaneseSemantics()
```
## 最佳实践
### 配置
```json
{
  "learning": {
    "language": "auto"
  }
}
```
### 性能
- 模式在初始化时编译为正则表达式
- 语言检测使用简单的字符范围检查
- 模式匹配使用预编译的正则表达式
### 扩展性
- 添加新语言只需创建两个文件
- 不需要修改核心逻辑
